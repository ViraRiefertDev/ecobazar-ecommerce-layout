# Ecobazar — E-commerce Layout

Responsive e-commerce website layout built with HTML, SCSS and vanilla JavaScript.

## Tech stack
- HTML5 (semantic markup)
- SCSS
  - mixins
  - adaptive typography
  - clamp-based responsive values
- Vanilla JavaScript
  - mobile menu interactions
  - touch device handling
  - dynamic header layout with matchMedia
- BEM methodology

## Features
- Responsive layout (320px → 1920px)
- Adaptive typography via SCSS mixins
- Accessible interactive states (`:hover`, `:focus-visible`)
- Mobile-friendly header:
  - burger menu with scroll lock
  - touch submenu behavior
  - dynamic element rearrangement on breakpoint
